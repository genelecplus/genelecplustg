GENELEC PLUS - GUIDE DE MISE EN LIGNE

1. Crée un compte sur https://github.com
2. Clique sur New repository.
3. Nom du dépôt : genelec-plus-site
4. Choisis Public puis Create repository.
5. Clique Add file > Upload files.
6. Envoie index.html et logo.png.
7. Clique Commit changes.
8. Va dans Settings > Pages.
9. Dans Source, choisis Deploy from a branch.
10. Branche : main ; dossier : / (root), puis Save.
11. Attends quelques minutes. GitHub affichera l'adresse du site.

IMPORTANT : cette version utilise une commande par formulaire/WhatsApp. Pour les paiements automatiques Flooz et Mixx by Yas, il faut un compte marchand et une passerelle/API autorisée. Ne publie jamais de clé secrète dans index.html.
